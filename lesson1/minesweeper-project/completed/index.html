FOLLOW THE CLICK

One object owns the game rules.

  1. Minesweeper stores the board and applies the rules.
  2. The page listens for a click and asks the game object to reveal a square.
  3. The page draws the updated board.
class Minesweeper {
  reveal(row, column) { ... }
  toggleFlag(row, column) { ... }

Ready for a server later: the class contains game rules and does not use HTML or the browser. Today this page creates the game object and draws its state. Later a server can own a game object and send the browser only what it needs to display.
Keep code together while learning: HTML, CSS, the game class, and page code are in this file. When the ideas feel familiar, we can move parts into separate files without changing the rules.
