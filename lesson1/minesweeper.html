Teacher notes: what is happening in the frontend?

The board is data. JavaScript keeps a 9 × 9 array. Each cell tracks whether it is a mine, revealed, or flagged. The browser draws buttons from that data.

A click is an event. The browser tells JavaScript which cell was clicked. JavaScript updates the game state, then redraws the board.

The page holds the game. The board and timer stay in this browser page. Refreshing starts a new round.

WALKTHROUGH PROMPTS

  1. What information does a number in one square represent?
  2. What data would JavaScript need to remember about each cell?

  4. Which function handles a cell click? Which function draws its new appearance?
