02 · A LITTLE STYLE

CSS changes how the page looks.

HTML names an element; CSS can change its color, spacing, and size. Select the button below to see a style change.

background: #315b45;
This rule gives the button a dark green background.

One rule, three parts

button means “find every button.” Braces hold the style instructions. color and background are properties; the values after the colon tell the browser what to use.

03 · A CLICK

JavaScript makes things respond.

A click is an event. JavaScript can listen for it, change information, and update the page.

Nothing has happened yet.

Follow the click

addEventListener('click', ...) means “when this button is clicked, run this instruction.” Inside the instruction, we change the message. Minesweeper follows the same idea: a square click changes the cell data, then the board is drawn again.

04 · GAME DATA

A square is a small collection of facts.

The game remembers what is true about every square. Here is one square before a game starts:

{
  row: 0,
  column: 0,
  isMine: false,
  nearbyMines: 0,
  isRevealed: false
}

row, column tell us where the square is.

isMine answers: is there a mine here?

nearbyMines stores the number to show.

isRevealed tells us whether the player has opened it.

05 · HOW THE BOARD GETS MADE

Make one square. Repeat it across the board.

Imagine a 3 by 3 board. A loop repeats the same small instruction once for each square. CSS Grid places the buttons into rows and columns.

What to notice

Each covered tile is a real button. One revealed tile shows 1: it has one neighboring mine. A corner has fewer neighbors than a middle square, so the code checks that a neighbor is still inside the board.

06 · A CLICK IN THE REAL GAME

Follow one click from start to finish.

Open the playable game in another tab if you like. Then follow this sequence for any square you click.

  1. Browser hears the clickThe button’s click listener identifies which square was chosen.
  2. JavaScript checks the squareHas the game ended? Is the square already open or flagged?
  3. Game data changesA safe square becomes revealed. A mine ends the round.
  4. Browser draws the new viewThe button shows a number, an empty space, a flag, or a mine.
Keep this sentence: click → check the data → change the data → draw the page again.
07 · THE ACTUAL MINESWEEPER CODE

A guided tour of the important lines.

The complete teacher game is more code because it handles every edge case. These are its main pieces, translated into plain language.

1. Set the board size and find the page elements
const ROWS = 9;
const COLUMNS = 9;
const MINE_TOTAL = 10;

const boardElement = document.getElementById('board');

const gives a name to a value we do not plan to replace. The first three lines describe our game. getElementById finds the empty board container in the HTML so JavaScript can put buttons inside it.

2. Describe one square
function makeCell(row, column) {
  return {
    r: row,
    c: column,
    mine: false,
    count: 0,
    revealed: false,
    flagged: false
  };
}

function names a reusable set of instructions. Each time makeCell is called, it returns one object: position, mine status, neighbor count, and what the player has done.

3. Create the board from rows and columns
function createEmptyBoard() {
  return Array.from({ length: ROWS }, (_, row) =>
    Array.from({ length: COLUMNS }, (_, column) =>
      makeCell(row, column)
    )
  );
}

The outer repeat makes rows. For each row, the inner repeat makes columns. Each position gets its own new cell. The result is a grid stored as cells[row][column].

4. Draw buttons from the data
function drawBoard() {
  boardElement.replaceChildren();
  cells.flat().forEach(cell => {
    const button = document.createElement('button');
    button.className = 'cell';
    button.addEventListener('click', () => revealCell(cell));
    boardElement.append(button);
  });
}

Clear the old board. Visit each cell. Make a button, give it a click listener, and add it to the board container. The full game also adds labels and flag behavior to each button.

5. Reveal a square
function revealCell(cell) {
  if (hasFinished || cell.flagged || cell.revealed) return;
  if (cell.mine) {
    finishGame(false);
    return;
  }
  cell.revealed = true;
  drawCell(cell);
}

The first line is a guard: if the game is over, or the square cannot be opened, stop here. If it is a mine, finish with a loss. Otherwise mark the data as revealed and update that square’s button.

6. Count neighboring mines
for (let rowOffset = -1; rowOffset <= 1; rowOffset++) {
  for (let columnOffset = -1; columnOffset <= 1; columnOffset++) {
    // Check the surrounding positions.
  }
}

Two small loops look at the row above, the same row, and the row below. They do the same for columns. Skipping the square itself leaves up to eight neighbors. Before using one, the full code checks it is still on the board.

7. Empty spaces open an area
if (cell.count === 0) {
  revealEmptyArea(cell);
} else {
  cell.revealed = true;
  drawCell(cell);
}

=== asks whether two values are equal. A zero means no neighboring mines, so the game opens the connected empty area. A numbered square only opens itself.

8. Reset starts with fresh data
function startNewGame() {
  cells = createEmptyBoard();
  drawBoard();
  updateCounters();
}

The actual reset also clears the timer and game flags. It creates a brand new board, draws it, and refreshes the counters. This is why reset does not need to reload the whole webpage.
